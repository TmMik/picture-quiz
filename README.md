# 🖼️ Picture Quiz

Онлайн игра с загадками и картинками. Угадывайте предметы по изображениям и зарабатывайте очки!

## 🎮 Особенности

- 🖼️ Загадки с картинками
- 💡 Система подсказок
- 📊 Система очков и уровней
- 📱 Адаптивный дизайн для мобильных устройств
- 📺 Google AdSense интеграция
- 🎨 Красивый современный интерфейс
- ⚡ Быстрая загрузка

## 🚀 Быстрый старт

### Требования
- Современный браузер (Chrome, Firefox, Safari, Edge)
- Интернет соединение

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/TmMik/picture-quiz.git
cd picture-quiz
```

2. Откройте `index.html` в браузере

### Или используйте Live Server
```bash
# Если у вас установлен Python 3:
python -m http.server 8000

# Или используйте VS Code Live Server расширение
```

После этого откройте http://localhost:8000 в браузере.

## 📝 Добавление своих загадок

Отредактируйте файл `js/riddles.js` и добавьте новые загадки:

```javascript
{
    id: 11,
    image: 'https://example.com/image.jpg',
    answer: 'ответ',
    alternatives: ['ответ', 'альтернатива'],
    hint: 'Подсказка к загадке',
    difficulty: 1
}
```

### Параметры загадки:
- **id** - уникальный номер
- **image** - URL изображения (используйте Unsplash или другие сервисы)
- **answer** - основной ответ (на русском языке)
- **alternatives** - альтернативные варианты ответа
- **hint** - подсказка для игрока
- **difficulty** - сложность (1 легко, 2 среднее, 3 сложно)

## 📺 Настройка Google AdSense

1. Зарегистрируйтесь на [Google AdSense](https://www.google.com/adsense/start/)
2. Получите ваш Publisher ID
3. Замените `ca-pub-xxxxxxxxxxxxxxxx` на ваш ID в файле `index.html`:

```html
<!-- Найдите и замените -->
client=ca-pub-xxxxxxxxxxxxxxxx
```

4. Замените также `data-ad-slot` на ваши слоты объявлений

## 🎯 Правила игры

- **Правильный ответ**: +100 очков (или +50 если использована подсказка)
- **Неправильный ответ**: -25 очков
- **Использована подсказка**: -10 очков
- **Пропущена загадка**: -10 очков
- **Каждые 5 правильных ответов**: +1 уровень
- **3 подсказки** за игровую сессию
